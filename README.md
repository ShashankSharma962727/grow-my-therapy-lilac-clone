# Grow My Therapy – Internship Assignment (Stage 2)

This project is my submission for **Stage 2: Practical Assignment** of the Grow My Therapy Front-End Developer Internship.  
It includes a complete homepage clone, redesign, and custom section built using **Next.js** and **Tailwind CSS**.

---

## 🟩 Part 1: Homepage Clone
This repository contains a clone of the [Lilac Template](https://lilac-template.squarespace.com/) recreated in Next.js and Tailwind CSS.

### ✅ Completed
- Layout structure accurately replicated  
- Fully responsive across desktop, tablet, and mobile  
- Fonts, colors, and spacing match the original  
- Reusable Tailwind theme classes for maintainability  

---

## 🟦 Part 2: Redesign Using Dr. Maya Reynolds’ Profile
The homepage was redesigned using the fictional therapist **Dr. Maya Reynolds, PsyD** profile as the main content source.

### 🔄 Updates Made
- Rewrote all website copy based on Dr. Maya’s profile  
- Replaced colors and fonts with a calm, therapy-focused palette  
- Added new images reflecting themes of growth, calm, and reflection  
- Applied SEO keywords (e.g., *Therapy in Santa Monica*)  
- Maintained accessibility and readability across all screen sizes  

---

## 🟨 Part 3: Custom “Our Office” Section
A new custom section was added beyond the original template.

### ✨ Features
